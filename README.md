# RCSnet
Rock crack segmentation algorithm

<img width="944" height="551" alt="8b86a7c7-fadf-4574-a8f2-ed42e9b0ec2a" src="https://github.com/user-attachments/assets/6b9bdb11-1ea1-4d22-8085-dc9cdad61d4a" />

If you want to train your data, please run RCSnet.py

If you want to test your trained model, please run RCSnet_index.py

You can directly download the model weights through the link: https://www.kaggle.com/models/sawhllow/rcsnet

First, change the SegmentationModel function in othersModel.py to obtain other comparison models, and then run compare to obtain the comparison images of the predicted masks and ground truths of each model.

Code will be released gradually
